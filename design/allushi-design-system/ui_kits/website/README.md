# Allushi website UI kit

The allushi.io / allushi.ai marketing site — the studio's only product surface. The old
joanisallushi.com portfolio is deprecated; this kit is the step-up direction built on the new
foundations (ink/paper bands, signal green, mono layer).

Screens/sections (all composed into `index.html`, one interactive page):

- `Nav.jsx` — sticky blurred nav, wordmark, accent CTA
- `Hero.jsx` — dark band, mono kicker, display headline, terminal card, sectors meta row
- `Services.jsx` — four service cards with Lucide icons + stack tags
- `Work.jsx` — Tabs-filtered case studies (image placeholders — no real case imagery exists yet)
- `Process.jsx` — dark band, numbered mono steps
- `Contact.jsx` — brief form (Input/Select/Checkbox/Button) with fake submit → Toast
- `Footer.jsx` — ink footer, white wordmark

Interactions: work filtering, form validation + toast, smooth-scroll nav.
Case studies are illustrative sample content (sector-true, no real client names).
