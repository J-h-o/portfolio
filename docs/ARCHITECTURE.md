# ARCHITECTURE.md — Current Flutter app (legacy)

Analysis of the existing codebase as of the last real commit (`0065c1e cv section`, March 2022). The app now lives under `legacy/` and is a **content/design reference only**; active work goes into the Next.js app at the repository root.

## Overview

Single-page Flutter Web app. One route (`Home`), rendered as a scrollable column: `Header` → `Carousel` (hero) → `Cv` → `JobExperience`. Dark theme, Google Fonts (Oswald for display, Lato for body), responsive via `responsive_framework` + a custom `ScreenHelper` (breakpoints: mobile <800, tablet 800–1199, desktop ≥1200).

## Known issues (why this can't just be "finished")

1. **SEO-hostile by construction.** Flutter Web paints to canvas; `web/index.html` ships `<title>portfolio</title>` and `description: "A new Flutter project."`. Crawlers see nothing. This is the core driver for the Next.js rebuild.
2. **Won't build on modern toolchains.** Dart SDK constraint `>=2.15.1 <3.0.0`; deps from 2022 (`responsive_framework 0.1.7`, `google_fonts 2.3.1`, `carousel_slider 4.0.0`). Current Flutter ships Dart 3.x.
3. **Dead navigation** — every nav/logo/CTA `onTap` is `() {}`.
4. **Placeholder experience data** — hero content copy-pasted into the job section; empty data lists.
5. **5 identical hero slides** — carousel generates the same slide five times.
6. **Stale CV link** — external Firebase URL to a 2022 "Junior Developer" resume; may 404 and no longer reflects seniority.
7. Unused `android/`, `ios/` targets and `kPrimaryColor`; only default widget test exists.
